# Model-SIET: โมเดล 3 มิติ คณะครุศาสตร์อุตสาหกรรมและเทคโนโลยี สจล.

โมเดล 3 มิติของอาคารคณะครุศาสตร์อุตสาหกรรมและเทคโนโลยี (SIET) สถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง ริมถนนฉลองกรุง
เป็นหน้าเว็บที่หมุน ซูม และเลือกมุมกล้องได้ สร้างด้วย [three.js](https://threejs.org/)

## เปิดดู

- **เปิดไฟล์ `index.html`** ในเบราว์เซอร์ได้เลย (ต้องต่ออินเทอร์เน็ต เพราะโหลด three.js จาก CDN)
- **GitHub Pages**: ไปที่ Settings → Pages → Source เลือก `main` / `(root)` แล้วจะได้ลิงก์เว็บไว้แชร์
- **ไฟล์โมเดล** `model/SIET_KMITL_model.glb` เปิดได้ใน Blender, PowerPoint (แทรก → โมเดล 3D), Windows 3D Viewer หรือ https://gltf-viewer.donmccurdy.com/

## ความแม่นยำ

- **ผังอาคาร** วัดจากภาพดาวเทียม Google Maps ที่ซูมระดับ 20 (ราว 0.15 ม./พิกเซล) ตำแหน่งและขนาดในแนวราบคลาดเคลื่อนได้ราว 1–2 ม.
- **ความสูงและจำนวนชั้น** ประมาณจากภาพถ่าย ภาพ Street View และประวัติคณะ อาคารด้านหลังที่ไม่มีรูปด้านข้างอาจคลาดได้ 1 ชั้น
- **มุมกล้อง** ลานน้ำพุ ถนนฉลองกรุง และมุมโดรน คำนวณตำแหน่งกล้องจากจุดอ้างอิงในภาพถ่ายจริง (`tools/solvecam.py`)
- รายละเอียดผนัง หน้าต่าง และต้นไม้เป็นแบบย่อ ไม่ได้ทำตามแบบก่อสร้างจริง

## แก้ไขและสร้างใหม่

```bash
npm install                # ติดตั้ง three.js 0.170.0 ไว้ใช้แบบออฟไลน์
python3 build.py           # รวม src/ เป็น index.html (CDN) และ test.html (node_modules)
python3 -m http.server 8765
# เปิด http://localhost:8765/test.html
```

- `src/page.html`: หน้าเว็บและ UI
- `src/js/00_setup.js`: renderer, วัสดุ, พื้นผิว, ฟังก์ชันช่วยสร้างรูปทรง
- `src/js/10_env.js`: ท้องฟ้า แสง พื้น ถนน ทางรถไฟ อาคารรอบข้าง
- `src/js/20_tower.js`: อาคารนวัตกรรมการเรียนรู้ โครงเหล็กถัก หลังคาทางเข้า ปีกขั้นบันได
- `src/js/30_front.js`: ลานน้ำพุ ตัวอักษร SIET อาคารฝั่งหน้า
- `src/js/40_back.js`: อาคารด้านหลัง ลานกีฬา โรงอาหาร สโมสร
- `src/js/50_details.js`: ต้นไม้ รถ สะพานลอย เสาไฟ
- `src/js/90_main.js`: มุมกล้อง ป้ายชื่อ ปุ่มต่าง ๆ

พิกัดในโค้ดเป็นเมตร: `x` ไปทางตะวันออก, `z` ไปทางใต้ จุด (0, 0) อยู่ที่มุมตะวันตกเฉียงเหนือของภาพดาวเทียมที่ใช้วัด

ทุกครั้งที่แก้ไฟล์ใน `src/` แล้ว push ขึ้น main, GitHub Actions (`.github/workflows/build.yml`) จะสร้าง `index.html` และ `model/SIET_KMITL_model.glb` ใหม่แล้ว commit ให้เอง

ส่งออกไฟล์ `.glb` เองบนเครื่อง: `pip install playwright` แล้วรัน `python3 tools/export_glb.py model/SIET_KMITL_model.glb` (ต้องเปิด http.server ไว้)
